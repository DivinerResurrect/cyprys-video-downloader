## Features

- **Download a video from a link.** Paste the page address and see every available format with its file size before anything is downloaded.
- **Choose the quality.** 4K, 1080p Full HD, 720p or best available, as a one-time default or per video.
- **Video to MP3.** Save only the audio as MP3, M4A, WAV or OPUS. Video as MP4, MKV or WEBM.
- **Whole playlists.** Paste a playlist link and every video is queued with the same settings.
- **Subtitles.** Save subtitles in the languages you choose, when the video has them.
- **Tidy files.** Thumbnail and title embedded in the file, saved to the folder you pick.
- **No ads, no account.** No pop-ups, no fake download buttons, no browser extension.
- **Portable.** One .exe, nothing to install.

## How to Install

1. Go to the [Cyprys website](https://divinerresurrect.github.io/cyprys-video-downloader/) and click **Download for Windows**.
2. Your browser saves `CyprysVideoDownloader.zip` to the Downloads folder.
3. Right-click the ZIP file and choose **Extract All**.
4. Open the extracted folder and double-click `CyprysVideoDownloader-portable.exe`. There is nothing to install.
5. If Windows SmartScreen shows a warning, click **More info**, then **Run anyway**. This is normal for free, unsigned open-source apps.

## How to Download a Video from a Website

Copy the address of the page that contains the video. In Cyprys, press **Paste**: the app reads the page and lists every format the site offers, from 4K down to audio only, with the size of each file. Select one and press **Download**. The video is saved to `Videos\Downloads` by default, and you can change the folder in the settings.

To save a whole playlist, paste the playlist link instead of a single video. With **Whole playlist from one link** turned on, every video in it goes to the queue with the same quality and format. The queue shows progress, download speed and time left for each file.

## How to Save a Video as MP3

Choose **Audio only** in the format list, or set MP3 as the default audio format. Cyprys saves just the sound track, which is useful for lectures, talks and podcasts you are allowed to keep.

## FAQ

### How do I download a video in 1080p or 4K?

After you paste the link, pick 1080p or 2160p (4K) from the list of formats. If a site does not offer a 4K version, the app cannot create one.


### Does it need a browser extension or an account?

No. It is a standalone Windows app. There is no extension to install and no account to create.

### Does it work on Windows 11?

Yes. It runs on Windows 11 and Windows 10, 64-bit.
